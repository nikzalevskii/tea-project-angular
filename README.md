# Tea Catalog

A website built with Angular featuring a tea catalog and a fully implemented search functionality.

## Features
- Browse a variety of teas in the catalog.
- Search for teas using the integrated search bar.
- Built with Angular for a dynamic and responsive user experience.

## Live Demo
Check out the website here: (https://nikzalevskii.github.io/tea-project-angular/)

## Technologies Used
- **Frontend**: Angular
- **Styling**: CSS
